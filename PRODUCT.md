# CogniJuegos / ASISTODO
<!-- impeccable:product-schema 1 -->
## Platform
web
## Users
Latest user direction prioritizes older adults: calm dark cognitive styling, clear reading, useful information and inviting game choices.
## Product Purpose
Offer familiar daily word, attention and logic games, plus narrative choices.
## Capabilities and Constraints
Five existing games and their calendar routes; guest and authenticated access; real points and streaks; administrator-only narrative editor. React, Ionic and Capacitor. Shared visual language covers the main menu, calendars, navbar and four classic games; King’s Court remains outside this pass. No invented health claims, rewards or progress.
## Brand Commitments
User requests dark cognitive styling with distinct game accents; avoid an all-blue blended appearance. Preserve ASISTODO identity and Spanish voice. User authorizes implementation and push for review.
## Evidence on Hand
Existing game catalog, auth and economy context, public/asistodo-logo.svg, repository documentation.
