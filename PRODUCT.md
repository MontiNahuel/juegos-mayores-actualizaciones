# CogniJuegos / ASISTODO

## Platform
web
## Users
User confirms a more playful experience for a general audience. Existing games also serve older adults; preserve legibility and straightforward controls.
## Product Purpose
Offer familiar daily word, attention and logic games, plus narrative choices.
## Capabilities and Constraints
Five existing games and their calendar routes; guest and authenticated access; real points and streaks; administrator-only narrative editor. React, Ionic and Capacitor. This design trial changes only the main menu and its navbar. No invented health claims, rewards or progress.
## Brand Commitments
User requests cognitive blues, synergy and gamification. Preserve ASISTODO identity and Spanish voice. User authorizes implementation and push for review.
## Evidence on Hand
Existing game catalog, auth and economy context, public/asistodo-logo.svg, repository documentation.
